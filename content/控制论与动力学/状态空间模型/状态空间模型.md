# 状态空间模型 (State Space Models / SSMs)

## 概述

状态空间模型（SSM）是描述动态系统的经典框架，近年来与深度学习结合产生了强大的模型（如 Mamba）。

## 经典 SSM

### 连续时间
```
dx(t)/dt = A x(t) + B u(t)
y(t) = C x(t) + D u(t)
```

### 离散时间
```
x_t = A x_{t-1} + B u_t
y_t = C x_t + D u_t
```

## SSM 与深度学习的结合

### 核心思想
用神经网络参数化状态转移矩阵 A, B, C

```python
class SSM(nn.Module):
    def __init__(self, d_model, d_state):
        super().__init__()
        self.A = nn.Parameter(torch.randn(d_model, d_state))
        self.B = nn.Parameter(torch.randn(d_state, d_model))
        self.C = nn.Parameter(torch.randn(d_model, d_state))

    def forward(self, u):
        # 离散 SSM 前向传播
        x = torch.zeros_like(self.A)
        outputs = []
        for t in range(len(u)):
            x = self.A @ x + self.B @ u[t]
            y = self.C @ x
            outputs.append(y)
        return torch.stack(outputs)
```

## Mamba (2024)

选择性状态空间模型（Selective State Space Model）：

1. **选择性机制**：根据输入动态选择处理哪些状态
2. **硬件优化**：并行扫描算法
3. **高效推理**：线性复杂度

```python
# Mamba 核心结构
class MambaBlock(nn.Module):
    def __init__(self, d_model, d_state=128):
        self.ssm = SSM(d_model, d_state)
        self.norm = RMSNorm(d_model)

    def forward(self, x):
        x = self.norm(x)
        x = self.ssm(x)
        return x
```

## SSM vs Transformer

| 特性 | Transformer | SSM (Mamba) |
|-----|------------|-------------|
| 复杂度 | O(N²) | O(N) |
| 推理 | 二次 | 线性 |
| 记忆 | 完整 | 压缩 |
| 并行 | 有限 | 高效 |

## 应用场景

- **长序列建模**：基因组、音频、视频
- **时序预测**：金融、气象
- **语言建模**：Mamba 已在语言任务上展现实力
