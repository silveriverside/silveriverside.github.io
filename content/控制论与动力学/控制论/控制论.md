# 控制论 (Control Theory)

## 概述

控制论研究系统的调节和控制，涉及反馈、稳定性、优化等核心概念。它是现代工程和科学的核心学科，与深度学习有深刻联系。

## 基本概念

### 系统
- **状态空间**：描述系统所有可能状态
- **输入/输出**：系统与环境的交互

### 反馈
将系统输出部分返回到输入端
- **负反馈**：趋向目标
- **正Feedback**：增强或放大

### 控制
- **开环控制**：仅基于预定指令
- **闭环控制**：基于反馈调整

## 核心理论

### 稳定性
- **Lyapunov 稳定性**：小扰动导致小偏差
- **渐近稳定**：扰动后回归平衡
- **全局稳定**：整个状态空间

### 最优控制
最小化性能指标：
```python
# 典型最优控制问题
def optimal_control():
    # 目标：最小化总成本
    J = integral(L(x, u, t) dt)
    # 约束：系统动力学
    dx/dt = f(x, u)
    # 边界条件
    x(0) = x0, x(T) = xT
```

### 鲁棒控制
处理不确定性和扰动

## 与深度学习的联系

### 1. 系统辨识
使用神经网络学习动态系统

### 2. 强化学习
本质是最优控制问题

### 3. 神经网络控制
- 控制神经网络的训练
- 用控制理论理解优化器

### 4. 物理-informed 神经网络
将物理规律（微分方程）融入网络

## 关键定理

### Lyapunov 稳定性定理
如果存在正定函数 V(x) 使得 dV/dt < 0，则系统渐近稳定

### PID 控制
- P：比例控制
- I：积分控制
- D：微分控制
