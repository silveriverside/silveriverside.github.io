# 吸引子 (Attractor)

## 概述

吸引子是动力系统中长期稳定的状态或行为模式。在神经网络中，吸引子理论用于理解记忆存储、模式完成和计算能力。

## 数学定义

### 动力系统
```
dx/dt = f(x)
```

### 吸引子类型

1. **点吸引子**：系统收敛到单一稳定点
2. **极限环吸引子**：周期性振荡
3. **奇异吸引子**：混沌系统（如 Lorenz）

## Hopfield 网络

经典联想记忆模型：
```python
class Hopfield(nn.Module):
    def forward(self, x, memory_patterns):
        # 检索最相似的记忆
        similarities = x @ memory_patterns.T
        retrieved = memory_patterns[argmax(similarities)]
        return retrieved
```

## 现代应用

### 1. 吸引子网络
- 模式完成
- 稀疏编码

### 2. 能量函数
```python
E = -1/2 * Σ w_ij * x_i * x_j - Σ b_i * x_i
```

### 3. 神经网络中的吸引子
- RNN 的固定点
- Transformer 的表示空间
