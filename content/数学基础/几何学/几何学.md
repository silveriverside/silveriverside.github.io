# 几何学 (Geometry)

## 概述

几何学研究空间、形状、大小以及它们之间的关系。从欧几里得到现代几何学，经历了深刻的发展。

## 发展历程

### 欧几里得几何
- 公理化体系
- 平行公设
- 平面和三维空间

### 非欧几何
- 双曲几何（罗巴切夫斯基）
- 椭圆几何（黎曼）
- 球面几何

### 射影几何
研究在射影变换下不变的性质

### 微分几何
使用微积分工具研究曲线和曲面

## 核心概念

### 度量空间
配备距离函数的集合

### 曲率
描述空间弯曲程度的量
- **高斯曲率**：内在曲率
- **黎曼曲率**：更一般的曲率张量

### 联络
在流形上定义平行移动

## 在深度学习中的应用

### 1. 3D 几何深度学习
- 点云处理
- 网格处理
- 体素表示

### 2. 等变性网络
- 旋转等变性
- 平移等变性
- 置换等变性

### 3. 几何先验
- 物理守恒定律
- 对称性约束

## 关键算法

### PointNet
直接在点云上操作：
```python
# PointNet 核心思想
def pointnet(x):
    # 每个点的特征提取
    h = mlp(x)  # 共享 MLP
    # 全局特征聚合
    global_feat = max_pool(h, dim=1)
    # 分类/分割
    return classifier(global_feat)
```

### 几何深度学习原理
Bronstein et al. 提出的 5G 框架：
1. **Grids**：规则网格（图像）
2. **Graphs**：图结构
3. **Groups**：对称群
4. **Geodesics**：测地线
5. **Gauges**：规范场
