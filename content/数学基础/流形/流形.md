# 流形与流形学习 (Manifold & Manifold Learning)

## 流形的定义

### 拓扑流形
局部同胚于欧几里得空间的拓扑空间。更准确地说，n 维流形是每个点都有一个邻域同胚于 ℝⁿ 的 Hausdorff 空间。

### 光滑流形
配备光滑结构的流形，允许微分运算。

### 嵌入流形
嵌入到更高维空间中的流形，如 S² 嵌入 ℝ³

## 常见流形类型

| 流形 | 描述 | 机器学习应用 |
|-----|------|------------|
| 球面 Sⁿ | 所有单位向量组成的集合 | 方向数据、三维旋转 |
| 环面 T² | 圆环面 | 周期数据 |
| 双曲空间 | 负曲率空间 | 网络嵌入 |
| Stiefel 流形 | 正交矩阵集合 | 神经网络权重 |
| SPD 流形 | 对称正定矩阵 | 协方差数据 |

## 流形学习

流形学习假设高维数据实际上位于低维流形上，旨在从高维观测中恢复低维流形结构。

### 经典算法

#### 1. ISOMAP
使用测地距离近似保持全局结构
```
1. 构建 k 近邻图
2. 计算最短路径作为测地距离
3. MDS 降维
```

#### 2. Locally Linear Embedding (LLE)
保持局部线性关系
```
1. 对每个点找到 k 近邻
2. 用近邻线性表示该点
3. 在低维保持相同权重
```

#### 3. t-SNE
基于概率的局部保持
- 使用 Student t 分布测量相似度
- 保留局部结构
- 常用于可视化

#### 4. UMAP
基于拓扑数据分析
- 使用模糊单纯复形
- 比 t-SNE 更快，保留更多全局结构

## 流形上的机器学习

### 黎曼梯度下降
在流形上进行优化，如球面卷积

```python
# 球面梯度下降示例
def riemannian_grad(grad, x):
    """将欧几里得梯度投影到切空间"""
    return grad - x * dot(x, grad)
```

### 几何深度学习与流形
- PointNet：直接在点云（流形）上操作
- 球面卷积：在 S² 上进行卷积
- 双曲嵌入：层次数据的嵌入

## 关键概念

### 切空间
流形在某一点的线性近似

### 黎曼度量
在流形上定义距离和角度

### 测地线
流形上的"直线"，最短路径
