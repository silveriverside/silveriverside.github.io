# 群论 (Group Theory)

## 概述

群论是抽象代数的核心分支，研究具有封闭运算的代数结构——群。它是描述对称性的数学语言，在物理学、化学和计算机科学中有广泛应用。

## 基本定义

### 群 (Group)
一个集合 G 配备二元运算 ·，满足：
1. **封闭性**：若 a, b ∈ G，则 a·b ∈ G
2. **结合律**：(a·b)·c = a·(b·c)
3. **单位元**：存在 e ∈ G，使得 e·a = a·e = a
4. **逆元**：每个 a ∈ G 存在 a⁻¹ ∈ G，使得 a·a⁻¹ = a⁻¹·a = e

### 子群 (Subgroup)
群 G 的子集 H，若 H 对 G 的运算也构成群

### 同构 (Isomorphism)
两个群之间存在双射 φ，使得 φ(ab) = φ(a)φ(b)

## 有限群与无限群

- **有限群**：群中元素个数有限
- **无限群**：如整数加群 (Z, +)

## 重要类型

### 1. 阿贝尔群 (Abelian Group)
运算满足交换律：ab = ba

### 2. 循环群
由单个元素生成：G = ⟨g⟩ = {e, g, g², ...}

### 3. 对称群 S_n
n 个元素的排列群，包含 n! 个元素

### 4. 李群 (Lie Group)
同时是微分流形，如 SO(3), SU(2)

## 在机器学习中的应用

### 对称性建模
**等变性 (Equivariance)**：对称变换下的性质保持

```python
# 等变性示例：旋转等变性
# 如果输入旋转 θ，输出也旋转 θ
class EquivariantLayer(nn.Module):
    def forward(self, x, theta):
        # 旋转输入
        x_rotated = rotate(x, theta)
        # 通过网络
        out = self.net(x_rotated)
        # 输出也是旋转的
        return rotate(out, -theta)
```

### 图神经网络中的对称性
- 节点排列不变性
- 子图结构对称性

### 物理启发的神经网络
- 能量守恒
- 动量守恒

## 关键定理

### Lagrange 定理
有限群的子群阶数整除原群阶数

### Cayley 定理
任何群同构于某个对称群的子群
