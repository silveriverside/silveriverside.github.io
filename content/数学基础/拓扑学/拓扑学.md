# 拓扑学 (Topology)

## 概述

拓扑学是数学的一个分支，研究空间的连续性质，即在连续变形下不变的几何属性。它被称为"橡皮几何学"，因为它允许空间自由伸缩和扭曲，只要不撕裂或粘合。

## 基本概念

### 开集与闭集
- **开集**：不包含边界的点集
- **闭集**：包含所有极限点的点集

### 连续映射
如果映射 f: X → Y 满足：对于 Y 中的每个开集，其原像在 X 中也是开集，则 f 是连续的。

### 同胚 (Homeomorphism)
两个空间之间存在双射且双方都连续的映射。如果两个空间同胚，它们在拓扑学意义上是"相同"的。

### 同伦 (Homotopy)
两条连续路径如果可以在空间中进行连续变形而相互到达，则它们同伦。同伦类形成基本群。

## 重要定理

### 欧拉-笛卡尔公式
对于凸多面体：V - E + F = 2
- V: 顶点数
- E: 边数
- F: 面数

### 不动点定理
- **Brouwer 不动点定理**：连续映射将紧凸集映射到自身时，必有一个不动点
- **Lefschetz 不动点定理**：更一般的拓扑学不动点定理

## 在机器学习中的应用

### 拓扑数据分析 (TDA)
使用拓扑方法分析数据的形状，发现数据的内在结构。

#### 持续同调 (Persistent Homology)
跟踪数据在不同尺度下的拓扑特征：
- 0维：连通分量
- 1维：环/洞
- 2维：空洞

```python
# 典型的 TDA 流程
from ripser import ripser
from persim import plot_diagrams

# 计算数据的持续同调
diagrams = ripser(data)['dgms']
plot_diagrams(diagrams)
```

### 图神经网络
- 图的连通性
- 图的环路结构
- 图的社区结构

### 流形学习
- 数据的内在低维结构
- 局部几何性质
