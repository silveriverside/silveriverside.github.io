# 信息论 (Information Theory)

## 概述

信息论由 Claude Shannon 1948 年创立，研究信息的量化、存储和传输。在机器学习中具有基础性作用。

## 核心概念

### 熵 (Entropy)
```python
H(X) = -Σ p(x) log p(x)
```

- 衡量不确定性
- 单位：bits (log₂) 或 nats (ln)

### 联合熵
```python
H(X, Y) = -Σ Σ p(x, y) log p(x, y)
```

### 条件熵
```python
H(Y|X) = H(X, Y) - H(X)
```

### 互信息
```python
I(X; Y) = H(X) + H(Y) - H(X, Y)
     = H(Y) - H(Y|X)
```

衡量两个变量共享的信息量。

## KL 散度 (Kullback-Leibler Divergence)
```python
DKL(P || Q) = Σ P(x) log(P(x) / Q(x))
```

- 非对称
- 衡量分布差异
- 用于变分推断

## 交叉熵
```python
H(P, Q) = -Σ P(x) log Q(x)
       = H(P) + DKL(P || Q)
```

## 在深度学习中的应用

### 1. 变分自编码器 (VAE)
```python
# 最大化 ELBO = -KL(q(z|x) || p(z)) + E[log p(x|z)]
# 实际使用: binary_cross_entropy + KL_divergence
```

### 2. 注意力机制
- 查询、键、值的互信息解释

### 3. 信息瓶颈
```python
min I(X; Z) - β I(Z; Y)
```
- 在压缩和表示之间平衡

### 4. 损失函数
- 交叉熵损失
- Focal Loss

## 最大熵原理

在约束条件下，选择熵最大的分布。
