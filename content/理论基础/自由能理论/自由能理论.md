# 自由能理论 (Free Energy Principle)

## 概述

自由能原理（FEP）由 Karl Friston 提出，是大脑和智能系统如何维持自身组织的理论框架。

## 核心概念

### 自由能
```python
F = E_q[log q(z|x) - log p(x, z)]
    = -ELBO (证据下界)
```

- 衡量系统与环境的"惊讶"程度
- 系统倾向于最小化自由能

### 变分自由能
```python
F = DKL(q(z|x) || p(z|x)) - log p(x)
```

## 核心思想

**智能体通过最小化自由能来维持自身存在**：

1. **感知**：推断隐状态
2. **行动**：改变环境以减少"惊讶"
3. **学习**：调整模型以更好预测

## 与机器学习的关系

### 1. 变分推断
```python
# VAE 的目标是最小化自由能
loss = reconstruction + KL(q(z|x) || p(z))
```

### 2. 主动推理
```python
# 选择最小化期望自由能的行动
a* = argmin_a E[F(s, a)]
```

### 3. 层次推理
- 感知 → 行动 → 学习 形成闭环

## 关键公式

### 精准编码
```python
p(x) = ∫ p(x|z) p(z) dz
log p(x) = -F(q) + DKL(q(z|x) || p(z|x))
```

### 主动推理
```python
# 行动选择
π = argmin_π E[F(π)]
```
