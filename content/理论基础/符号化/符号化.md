# 符号化 (Symbolic)

## 概述

符号化是将知识表示为离散符号和规则的方法，与神经网络的连接主义形成对比。

## 核心概念

### 符号系统
- **原子**：不可分的符号（如 A, B, C）
- **命题**：原子的组合
- **规则**：符号间的关系（if-then）

### 符号 vs 嵌入

| 特性 | 符号表示 | 分布式表示 |
|-----|---------|-----------|
| 可解释性 | 高 | 低 |
| 组合性 | 自然 | 涌现 |
| 推理 | 逻辑 | 模式匹配 |
| 学习 | 手工 | 数据驱动 |

## 现代方法

### 1. 神经符号 AI
结合神经网络和符号推理：
- Neural Theorem Prover
- DeepProbLog

### 2. 知识图谱
```python
# 符号化知识表示
(实体1, 关系, 实体2)
# 例: (北京, 首都, 中国)
```

### 3. 程序合成
```python
# 从示例生成程序
input → [f1, f2, ...] → output
```

### 4. 大语言模型 + 工具
- Chain of Thought
- ReAct
- Tool use

## 关键问题

### 1. 组合爆炸
符号组合数量随复杂度指数增长

### 2. 接地问题
符号如何与现实世界关联

### 3. 不确定性
如何处理模糊和概率信息

## 应用

- **定理证明**：Coq, Lean
- **知识推理**：OWL, RDF
- **程序合成**：AlphaCode, CodeGen
